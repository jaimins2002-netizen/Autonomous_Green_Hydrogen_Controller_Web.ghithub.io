Project, milestone by milestone

01 · SPECIFICATION

Milestone 1

Defines the four plant inputs, one production output, operating ranges, linguistic terms, triangular memberships, and expert-rule foundation.

I/O contractSource specification
02 · IMPLEMENTATION

Milestone 2

Implements the core Mamdani fuzzy controller with `scikit-fuzzy`, membership functions, rules, defuzzification, and the uploaded chemical-controller notebook.

Mamdani FLCNotebook implementation
03 · VALIDATION

Milestone 3

Exercises controller behavior, analyzes parameter influence, and presents a UI workflow with safety-focused demonstration cases.

01
Milestone 1 · Phase 2 · System Design

Read the controller contract

Begin with the formal source document. This milestone defines renewable power, water flow, stack temperature, and tank pressure as inputs, with hydrogen production rate as the output.

  1. Open the Milestone 1 page.
  2. Use the embedded PDF viewer to read the source specification.
  3. Review the readable I/O table and operating ranges.
  4. Use the Download PDF link if you need an offline copy.
View Milestone 1 specification →
02
Milestone 2 · Phase 3 · Python Implementation

Run the fuzzy controller notebook

Milestone 2 is the Phase 3 Python Implementation deliverable. It is notebook-only and contains the uploaded chemical-controller implementation. It uses triangular membership functions, an 11-rule expert knowledge base, Mamdani inference, and defuzzification.

  1. Open the Milestone 2 page or clone the Milestone 2 repository.
  2. Create and activate a Python environment.
  3. Install the notebook dependencies with pip install -r requirements.txt.
  4. Launch jupyter notebook ipynb/Milestone_2_Chemical_Controller.ipynb.
  5. Select Run → Run All Cells and scroll to the final cell for the SCADA-style interface.
cd autonomous-green-hydrogen-power-plant-controller-milestone-2
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
jupyter notebook ipynb/Milestone_2_Chemical_Controller.ipynb

Run the master integration tests

The integration repository vendors the relevant milestone interfaces and checks the Milestone 1 contract, Milestone 2 controller adapter, Milestone 3 evaluation behavior, safety response, and artifact presence.

cd autonomous-green-hydrogen-power-plant-controller-integration-tests
pip install -r requirements.txt
pytest -q
